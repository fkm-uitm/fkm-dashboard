About This Dashboard

FKM Research Analytics — data sourced from the UiTM Expert Portal

Data Source

All data is scraped from expert.uitm.edu.my — the UiTM Expert Portal where academic staff self-report their publications, grants, supervision and consultancy records. The scraper runs weekly (Monday 3 AM MYT) and updates the JSON files in this repository automatically.

Note: This dashboard reflects what staff have entered into the Expert Portal. It may differ from PRIME (the official UiTM reporting system) due to: different data sources, duplicate entries per co-author, or staff not having updated their Expert profile.

Export Data

Download the raw data as Excel files for offline analysis or reporting.

Technology

Built with vanilla HTML/CSS/JS, Chart.js, and GitHub Actions for automated scraping. Hosted on GitHub Pages.
