Technology

Built with vanilla HTML/CSS/JS, Chart.js, and GitHub Actions for automated scraping. Hosted on GitHub Pages.

Scope & Transparency

This dashboard covers active academic staff who have a profile on the UiTM Expert Portal. Publications, grants, supervision and consultancy records from retired, part-time (Sambilan), foreign contract (B.W. Negara), or temporary staff who do not appear on the portal are not included in any aggregate figures shown on this dashboard. Figures should therefore be read as a lower-bound estimate of FKM's research output.

How Data Is Collected

  1. Staff roster — a curated list of FKM academic staff slugs is maintained in data/members.csv (name, Expert Portal username, staff ID, designation). This list was seeded from the FKM staff directory and is updated manually when staff join or leave.
  2. Scraper — a Python script (scripts/scraper_expert.py) fetches each staff profile page from expert.uitm.edu.my/expert/{slug} and extracts the embedded Inertia.js JSON payload containing publications, grants, supervision and consultancy records.
  3. Transform — a second script (scripts/transform_expert.py) normalises the raw JSON into five flat datasets: staff, publications, grants, supervision, consultancy. Publications are classified by index (Scopus, WoS, ERA, MyCite, Other Indexed, Non-Indexed).
  4. Auto-update — a GitHub Actions workflow runs every Monday at 3 AM MYT, re-scrapes all profiles and commits the updated datasets to the repository. The dashboard on GitHub Pages reflects the latest commit automatically.

Known limitations: publication records reflect what each staff member has entered into their Expert Portal profile. The same paper may appear multiple times if co-authored by multiple FKM staff. Unique title-based deduplication is used for counts but minor differences in title formatting may cause undercounting or overcounting.
